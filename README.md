# Отладка приложения «Фибоначчи» в Visual Studio

В процессе разработки и тестирования консольного приложения были использованы встроенные инструменты отладки Visual Studio.

## Использованные инструменты отладки

### 1. Точки останова (Breakpoints)
- **Где установлены**:  
  - начало метода `Fibonacci()`;  
  - внутри цикла `for`;  
  - перед оператором `return`.

### 2. Пошаговое выполнение (Step‑by‑Step Debugging)
- **Команды**:  
  - `Step Over (F10)` — выполнение строки без захода в методы;  
  - `Step Into (F11)` — детальный анализ логики цикла.
- **Результат**:  
  - выявлена ошибка в условии цикла (`i < n` → исправлено на `i <= n`).

### 3. Окно «Локальные переменные» (Locals Window)
- **Функция**: автоматическое отображение всех переменных в зоне видимости.
- **Польза**:  
  - оперативный контроль состояния `n1`, `n2` при малых значениях `n`;  
  - визуализация изменений на каждой итерации.

### 4. Обработка исключений (Exception Settings)
- **Настройки**: остановка на всех исключениях (включая `ArgumentException`).
- **Эффект**:  
- мгновенное обнаружение некорректных входных данных (`n < 0`).

## Итоги отладки

Применение инструментов позволило:
-  **Локализовать** логическую ошибку в цикле;
-  **Проверить** граничные случаи (`n = 0`, `n = 1`);
-  **Добавить** обработку недопустимых входных данных;
-  **Верифицировать** корректность алгоритма для `n = 5` и других значений.
