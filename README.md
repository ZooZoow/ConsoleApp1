# Отладка приложения «ArrayExample» в Visual Studio

## Основные способы отладки

### 1. Точки останова (Breakpoints)
- **Где установлены**:  
  - в начале цикла `for` в методе `Main()`;  
  - внутри цикла — на строке вызова `SendMessage()`;  
  - в методе `SendMessage()` (для проверки передаваемых параметров).  
- **Цель**:  
  - контроль значений переменных `i`, `name`, `a[i]` на каждой итерации;  
  - проверка корректности передачи аргументов в `SendMessage()`.

### 2. Пошаговое выполнение (Step‑by‑Step Debugging)
- **Использованные команды**:  
  - `Step Over (F10)` — для выполнения строк без погружения в методы;  
  - `Step Into (F11)` — для детального анализа работы метода `SendMessage()`.  
- **Результат**:  
  - выявлена неэффективность операции `name += letters[i]`;  
  - подтверждено избыточное использование массива `a`.

### 3. Окно «Локальные переменные» (Locals Window)
- **Что отслеживалось**:  
  - содержимое массива `letters`;  
  - текущее значение строки `name` на каждом шаге цикла;  
  - значения элементов массива `a`.  
- **Польза**:  
  - визуальная проверка постепенного наращивания строки `name`;  
  - анализ динамики изменения счётчика в массиве `a`.


### 4. Окно «Контрольные значения» (Watch Window)
- **Добавлены выражения**:  
- **Преимущества**:  
- мониторинг ключевых параметров вне зоны видимости локальных переменных;  
- быстрая проверка условий (например, `i < letters.Length`).
