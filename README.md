# Отладка приложения «Galaxy News» 

## Инструменты отладки и их применение

### 1. Точки останова (Breakpoints)
- **Где установлены**:
  - в методе `IterateThroughList()` перед циклом `foreach`;
  - внутри цикла — на строке вывода в консоль;
  - в конструкторе `GType` (для отслеживания обработки типов галактик).

### 2. Пошаговое выполнение (Step‑by‑Step Debugging)
- **Использованные команды**:
  - `Step Over (F10)` — для выполнения строк без погружения в методы;
  - `Step Into (F11)` — для детального анализа логики в конструкторе `GType`.
- **Результат**:
  - выявлена ошибка в `switch` (`case 'l'` вместо `case 'I'`);
  - подтверждено некорректное присвоение типа для `Irregular`.

### 3. Окно «Контрольные значения» (Watch Window)
- **Добавлены выражения**:
- **Преимущества**:
- мониторинг ключевых свойств вне зоны видимости локальных переменных;
- сравнение фактических и ожидаемых значений в реальном времени.

### 4. Обработка исключений (Exception Settings)
- **Настройки**:
- активация остановки на всех исключениях (`Common Language Runtime Exceptions`).
- **Эффект**:
- мгновенное обнаружение потенциальных ошибок.
